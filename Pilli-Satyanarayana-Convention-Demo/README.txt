PILLI CONVENTION — WEBSITE DEMO 04

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted folder in VS Code (File > Open Folder).
3. Right-click index.html > Open with Live Server.

FILES
- index.html, about.html, facilities.html, gallery.html, contact.html
- style.css, script.js
- images/: local SVG image fallbacks used if external photos are unavailable

IMAGE NOTES
- One venue interior photograph is sourced from the public Trip.com listing for Pilli Satyanarayana Anantha Lakshmi Convention Hall: https://ak-d.tripcdn.com/images/0HJ2y12000hvr9vba94E5_W_960_0_R5_Q50.webp?proc=source%2Ftrip
- Remaining photographs load from Unsplash as illustrative event-styling references, NOT as verified photographs of this venue.
- Each image has a local SVG fallback, so an unavailable image does not show a broken-image icon.
- For the final business website, replace illustrative images with owner-approved photographs.
